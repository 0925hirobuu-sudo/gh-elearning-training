# 障がい者グループホーム 職員研修アプリ

このリポジトリは、障がい者グループホーム向けの職員研修アプリを GitHub Pages で公開するためのものです。

## 公開URL

GitHub Pages を有効化すると、次のURLでトップページを開けます。

https://0925hirobuu-sudo.github.io/gh-elearning-training/

## GitHub Pages の有効化

1. このリポジトリの `Settings` を開く
2. 左メニューの `Pages` を開く
3. `Build and deployment` の `Source` を `Deploy from a branch` にする
4. Branch を `main`、フォルダを `/ (root)` にする
5. `Save` を押す
6. 数分後に公開URLが有効になります
